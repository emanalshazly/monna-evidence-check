# Contributing

Please use synthetic or properly redacted data in issues and pull requests.
Include the Python/OS version, smallest manifest, expected result, actual
stdout/stderr and exit code. Never include API keys or private evidence.

Run `python -m unittest discover -s tests -v` before proposing a change. Keep
the standard-library-only runtime and separate structural evidence checks from
semantic claims. Add a regression case for a meaningful changed behavior.

Contributions intentionally submitted for inclusion are offered under this
repository's Apache-2.0 license, unless explicitly stated otherwise and agreed
before inclusion. You retain ownership of your contributions. Do not contribute
material you lack the rights to share. No ownership assignment is required.
